GPT Live Go — System Architecture

Realtime speech-to-speech + durable asynchronous reasoning · clients touch only live-gateway

Realtime speech path

  • • Client → gateway → S2S, 24 kHz PCM16LE
  • • Single serialized reactor boundary
  • • Epoch fence + incarnation drop stale output
  • • Bounded ingress/egress PCM queues

Durable async handoffs

  • • Reserved tools → PostgreSQL lease → worker
  • • CAS fencing: owner+version+revision
  • • Heartbeat loop + bounded full-jitter retry
  • • Idempotent, revision-fenced terminal writes

Deployment & security

  • • OIDC-only production auth (no static bearer)
  • • Config-hash drift guard, fail-closed
  • • Default-deny NetworkPolicy, non-root images
  • • Loopback-only admin, redacting logger
